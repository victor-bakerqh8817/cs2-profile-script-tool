## What It Does

CS2 Profile Injector gives Counter-Strike 2 users on Windows a dedicated way to manage local profile data, modify game-related files, and assemble reusable configurations. Its core workflows cover profile customization, configuration import and export, and guided scripting for common gameplay adjustments.

The utility is also designed for multilingual use and supports encrypted configuration files. For assisted generation, it can work with either the OpenAI API or Claude API. Overall, the project is aimed at making repeated profile and configuration tasks easier to organize, revise, and reproduce.
